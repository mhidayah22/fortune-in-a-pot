## The fortune

> Your keeper will water you on Thursday, forget on Friday, and apologise to you on Saturday as if you kept score.

One line, 112 characters. `main.py` writes it to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (then `/output` when it exists, then the folder holding the program).

## Run it

```sh
python3 main.py
```
